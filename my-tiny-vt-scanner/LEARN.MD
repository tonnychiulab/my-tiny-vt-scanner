# 📘 LEARN.MD - my-tiny-vt-scanner 學習筆記

嗨 JJ 哥！這份文件是專門為你寫的「專案導覽手冊」。這裡不會有生硬的技術名詞堆疊，只有我們開發這個小工具的思路與故事。

## 1. 這是什麼？為什麼要做它？

我們做這個 **my-tiny-vt-scanner**，是為了讓你的 WordPress 網站擁有一雙「照妖鏡」。

你知道 **VirusTotal (VT)** 嗎？它就像是資安界的「Google」，原本我們拿到一個可疑的 IP 或網址，都要手動複製去 VT 網站查。但這太慢了！所以我們寫了這個外掛，直接把 VT 的功能搬進 WordPress 後台。

**核心功能：**
*   **輸入 IP 或網址**：直接在後台打進去。
*   **即時掃描**：外掛會幫你跑去問 VirusTotal：「欸，這個 IP 乾淨嗎？」
*   **看報告**：馬上告訴你這是紅燈 (有毒)、黃燈 (可疑) 還是綠燈 (安全)。

## 2. 我們用了哪些技術積木？

要把這個功能蓋出來，我們用了幾個關鍵的積木：

### 🧱 PHP (後端大腦)
這是 WordPress 的母語。我們用它來：
*   **建立後台選單**：讓你在控制台看得到這個外掛。
*   **儲存設定**：幫你把珍貴的 API Key 存起來。
*   **跟 VT 溝通**：使用 `wp_remote_get` 這個函數。你可以把它和 VirusTotal 想像成打電話。

### ⚡ AJAX 與 REST API (傳令兵進化史)
原本我們用 **AJAX** (像只有我們懂的暗號)，現在我們升級成 **REST API** (國際通用的語言)！
*   **舊版 (AJAX)**：只有這個外掛自己看得懂，比較封閉。
*   **新版 (REST API)**：標準化接口 (`/wp-json/tiny-vt/v1/scan`)，以後如果你想寫一個手機 App 來控制它，也可以直接通！

### 💾 Transient Cache (快取記憶)
這是我們新加的「省錢大法」！
*   **原理**：當你在 1 小時內查同一個 IP，我們會直接從 WordPress 的腦袋 (資料庫) 撈出上次的結果，完全不用再去吵 VirusTotal。
*   **好處**：速度超快 (0.01秒 vs 1秒)，而且不會浪費你的 API 點數。

### 🛡️ API Key (通行證)
VirusTotal 雖然好用，但大門是有鎖的。我們需要一把 **API Key** (像是一張識別證) 才能進去查資料。
*   **小知識**：我們在程式裡做了一個「防呆裝置」。當你輸入 Key 儲存時，我們會**立刻**派信差去試用這把 Key 看看，如果是壞的或過期的，馬上告訴你。這樣才不會等到真的要救火時才發現鑰匙打不開門！

## 3. 我們學到了什麼？(踩坑筆記)

在開發過程中，我們特別注意了幾件事，這也是以後你看程式碼可以注意的點：

1.  **使用者體驗 (UX) 很重要**：
    我們沒有讓使用者猜「現在是在掃描嗎？還是當機了？」，而是加了一行字：「⏳ 正在進行圖譜掃描與分析...」。這一個小動作，就能讓使用者安心等待。

2.  **不要相信使用者的輸入**：
    JJ 哥這是資安鐵則！使用者輸入的 IP 可能是亂打的，網址可能忘了加 `http`。
    所以我們在程式裡加了 **「正規化檢查」 (Sanitization & Validation)**。
    *   如果是 IP，我們檢查它是不是長得像 `192.168.1.1` 這樣。
    *   如果是網址，我們檢查它有沒有 `http://` 開頭。

3.  **嚴格的型別宣告 (Strict Typing)**：
    這次改版我們加強了這點。以前 PHP 很隨便，給它數字它可能當文字處理。現在我們規定：「這個門只準進數字」，「那個門只準出陣列」。
    *   **好處**：程式更穩固，不會因為資料格式亂掉而產生奇怪的 Bug。

4.  **多國語系 (Internationalization / i18n)**：
    *   API 回傳的資料有 8 種狀態 (Malicious, Suspicious, Harmless, Undetected, Timeout, Confirmed-Timeout, Failure, Type-Unsupported)。
    *   我們把所有狀態都完整顯示出來，確保沒有死角。外國朋友要用這個外掛，我們只要提供一個翻譯檔 (如 `zh_TW.mo`, `ja.mo`)，外掛介面就會自動變成當地的語言！這就是走向國際化的第一步。

5.  **智慧偵測 (Smart Detection)**：
    *   程式變得更聰明，你輸入 `8.8.8.8` 它知道是 IP，輸入 `google.com` 它知道是網址。這就是「使用者體驗 (UX)」的提升，讓工具適應人，而不是人去適應工具。
    *   **[修正]** 我們也順便修正了一個小 bug：之前輸入 `google.com` 會卡住，因為程式不知道它是網址。現在我們會自動幫它穿上 `http://` 的外套，讓它能通過檢查。

6.  **除錯日誌 (Debug Log) 與戰情分析儀表板**：
    *   **[新介面]** 為了最大化螢幕利用率，我們把介面改成了「全螢幕戰情室」風格！
        *   **緊湊型工具列**：輸入框變成了上方的一條 Bar，不再佔用一大塊版面。
        *   **API 設定區優化**：我們把「儲存按鈕」移到了 API Key 輸入框的右邊，不只省空間，設定完順手按下去也更直覺。
        *   **左右分割**：左邊看結果，右邊看日誌，高度會自動填滿螢幕，不想捲動也可以看得很清楚。
    *   JJ 哥說「卡住了」很難查，所以我們加了一個黑底綠字的「除錯視窗」。
    *   它會即時顯示：我們正在做什麼？現在送出請求了嗎？收到回應了嗎？
    *   這就像是飛機的「黑盒子」，萬一出事了，我們看日誌就知道是哪裡斷掉了。

7.  **貼心捷徑 (Smart Actions)**：
    *   **頂部工具列整合**：為了更順手，我們把「🕵️ Shodan」和「📋 Copy」這兩個按鈕直接拉到了「Scan Now」旁邊。
    *   **三劍客合體**：輸入目標 -> 掃描 -> (看結果) -> 順手查 Shodan 或複製。三個動作一氣呵成，不用滑鼠跑上跑下。
    *   **貼心提示 (Tooltips)**：游標移到按鈕上，會告訴您這個按鈕是做什麼的 (例如：「會在分頁開啟 Shodan」)，減少操作的不確定感。
 
8.  **三位一體智慧偵測 (Smart Detection)**：
    *   **[新功能]** 系統現在長眼了！它會自己在後端判斷您餵給它的是什麼：
        *   `8.8.8.8` → **IP 位址** (顯示 🌐 圖示)
        *   `google.com` → **網域 (Domain)** (顯示 🏰 圖示)
        *   `http://google.com` → **網址 (URL)** (顯示 🔗 圖示)
    *   報表上也會清楚蓋章，讓您知道現在查的是主機還是頁面。

9.  **技術架構升級 (Under the Hood)**：
    *   **結構重構**：為了符合 WordPress 官方標準，我們把 CSS 和 JS 拆分到了獨立的 `assets/` 資料夾。
    *   **標準化移除**：新增了 `uninstall.php`，確保移除外掛時不留垃圾。
    *   **標準文件**：新增了 `readme.txt`，隨時可以打包上架。

10. **品牌形象與安裝細節 (Branding & Installer Insights)**：
    *   **安裝程式的小秘密**：我們發現 WordPress 的安裝程式(Installer)在顯示版本需求時，主要是讀取 **PHP 主檔案** 開頭的註解，而不完全是看 `readme.txt`。所以這兩個檔案的資訊必須同步，才不會讓使用者誤會。
    *   **品牌一致性 (Consistency)**：為了讓外掛看起來更專業，我們統一了所有地方的名稱：
        *   **外掛列表**：正式名稱為 **My Tiny VT Scanner** (不再是小寫的 `my-tiny-vt-scanner`)。
        *   **後台選單**：統一使用 **My Tiny VT Scanner**，與頁面標題呼應。
        *   **頁面標題**：保持一致，加強品牌印象。
        *   **細節決定成敗**：這些小地方雖然不影響功能，但會大大影響使用者對產品的信任感。

## 6. 未來可以更好的地方

雖然現在能用了，但身為追求完美的團隊，我們知道還有進步空間：

*   **歷史紀錄**：現在掃完就沒了。未來可以把掃描過的壞 IP 記下來，下次它再來就直接擋掉！
